## 1. هيكل مسارات المستخدم (User Flows)

### المسار (أ): المستخدم الزائر (غير مسجل)
- يمر بـ `Splash` -> `Onboarding` -> `Login/SignUp`.
- عند محاولة الحجز، يظهر **طبقة منبثقة (Modal)** لتسجيل الدخول.

### المسار (ب): المستخدم المسجل (مشجع عادي)
- يمر بكل المسارات من `Home` -> `Discovery` -> `Checkout` -> `Post-Booking`.

### المسار (ج): المشجع الموسمي (حامل البطاقة الموسمية)
- نفس مسار (ب) مع إضافة زر **"تفعيل التذكرة الموسمية"** داخل شاشات `Match Details` أو `Payment` لخصم القيمة بالكامل.

## 3. مسارات إضافية (خارج نطاق المستخدم الأساسي)

### لوحة تحكم الإداريين (Admin Panel) - (5 شاشات منفصلة)
*تعتبر تطبيق ويب منفصل أو قسم مخفي، وليست جزءاً من شاشات المستخدم النهائي.*

1. **إدارة المباريات:** إضافة/تعديل/حذف المباريات والمواعيد.
2. **تحديد الأسعار:** تعيين أسعار الفئات (A, B, C) لكل مباراة.
3. **التحكم في القطع:** فتح/إغلاق قطع الملعب للمبيعات.
4. **مراجعة طلبات VIP:** إدارة طلبات كبار الزوار.
5. **إحصائيات الحضور:** عرض رسوم بيانية لمبيعات التذاكر ونسب الحضور.
