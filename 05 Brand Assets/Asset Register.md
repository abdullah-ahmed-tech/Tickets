# Brand Asset Register

The files in this folder are copies of the assets supplied for the Tazakir design. Original filenames are preserved so references and provenance remain recognizable. They are **design assets**; production use rights for club and competition marks still require confirmation.

| Group | Files | Intended use |
|---|---|---|
| Tazakir wordmark | `SVG/Primary Logo - lightmode.svg`, `SVG/Primary Logo - Darkmaode.svg`, and matching PNG files | Brand mark in Splash, admin shell, and marketing contexts. Light/dark variants were supplied. |
| App icon | `App Icon .png` | 1024×1024 application icon source. |
| Club and competition crests | `Teams Logos/*.png` | Fixture cards, catalogs, ticket details, and admin forms. Includes the supplied clubs plus CAF and Egyptian Premier League marks. |

Use a neutral placeholder for a club without a supplied authorized crest. The admin club catalog must support uploading new opponent crests, especially for continental fixtures. Do not infer that possession of an image file alone grants production or promotional rights.
